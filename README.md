# Дела

Планировщик: задачи с дедлайнами и подзадачами, календарь (работа / учеба / всё вместе) и нагрузка по неделям.
Данные хранятся в браузере (localStorage). Сборка не нужна: открой `index.html`.

## Публикация на GitHub Pages
1. Создай репозиторий и загрузи эти файлы в корень.
2. Settings → Pages → Branch: `main`, папка `/ (root)` → Save.
3. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.
